# BORDAXIS

2人対戦型のライン・エリア戦略ゲームのプロトタイプです。

## GitHub Pages

`.github/workflows/pages.yml` により、`main` ブランチへ push されるたびに GitHub Actions が自動で GitHub Pages を更新します。

初回のみ、GitHub のリポジトリ画面で **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。

以後は変更ファイルを `main` に反映するだけで、ページが自動更新されます。

## 開発運用

- 差分ZIPのみで更新
- ZIP名: `bordaxisvXX.zip`
- ZIPには変更・追加したファイルだけを含める
