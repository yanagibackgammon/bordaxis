# LINE TERRITORY - prototype

ブラウザだけで動く2人対戦ゲームの試作版です。サーバーや外部ライブラリは不要です。

## 起動
`index.html` をブラウザで開いてください。GitHub Pagesにそのまま配置しても動作します。

## 現時点で置いている仮仕様
- 10×10の正方形フィールド、11×11の格子点
- 各プレイヤー2駒
- A: (0,0)-(10,10)、B: (0,10)-(10,0) から開始
- 初期の2本の対角線も各プレイヤーの確定線として扱う
- 1 MOVE = 隣接格子点への1ステップ（縦・横・斜めの8方向）
- 全駒は同じ点に重ならない
- 1ターンは必ず3 MOVE
- 3 MOVE終了時の2駒を結ぶ線分を、そのプレイヤーの線として累積
- 自分の線だけで外部から遮断された領域の総面積を得点とする
- 盤の外周は「囲う線」として数えない
- 50ラウンド = 各プレイヤー50ターン、計100ターン
- 得点面積は試作版では高解像度ラスタ判定による近似値

## 次に決めたい点
1. 1 MOVEは8方向1マスでよいか。それとも上下左右4方向のみか。
2. 「50ターン」は各プレイヤー50ターンか、両者合計50ターンか。
3. 相手駒と同じ点への進入を禁止するか。
4. 自分・相手の線を駒が横切ってよいか。
5. 既存の線と完全に重なる線を許可するか。
6. 得点は「現在囲っている総面積」か、「新たに囲った面積をその都度加算」か。
7. 囲まれた領域が後からさらに線で分割された場合、総面積は同じ扱いでよいか。
8. 面積は小数で表示するか、何らかの整数化ルールを設けるか。
